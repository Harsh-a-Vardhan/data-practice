# data-practice

My ongoing practice solving SQL, pandas, and data problems, from DataLemur, LeetCode,
and others, as I upskill for Technical Program Manager and Forward Deployed Engineer roles.

Each file is one problem: where it came from, its difficulty, the question in my own
words, my solution, and a short note on what tripped me up or what I learned.

## Topics
- [SQL · Joins](sql/joins)
- [SQL · Window Functions](sql/window-functions)
- pandas (coming soon)

More topics get added as I practice them.

## How it's organized
One folder per topic, one file per problem. GitHub doesn't tag files, so folders are the
filtering. File names start with the difficulty so they sort naturally within a topic,
for example `easy-users-third-transaction.sql`.
